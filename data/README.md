# Dataset

All data in this project is **synthetic**. No real patient data is used.

It is generated by `src/generate_data.py`:

```
python src/generate_data.py
```

Output: `data/synthetic_patients.csv` (50 patients x 14 days, one row every 5 minutes, about 200,000 rows).

## Columns

| Column | Unit | Description |
|---|---|---|
| `patient_id` | - | Patient identifier (P001 to P050) |
| `timestamp` | - | Date and time, every 5 minutes |
| `glucose` | mg/dL | Simulated continuous glucose reading |
| `heart_rate` | bpm | Simulated heart rate (lower at night, higher with steps) |
| `steps` | steps / 5 min | Steps in the 5-minute window |
| `sleep_hours` | hours | Previous night's sleep (same value for the whole day) |
| `age` | years | Static EHR feature |
| `sex` | M / F | Static EHR feature |
| `bmi` | kg/m2 | Static EHR feature |
| `hba1c` | % | Static EHR feature, drives baseline glucose and meal response |
| `years_since_diagnosis` | years | Static EHR feature |
| `spike_2h` | 0 / 1 | Label: 1 if glucose exceeds 180 mg/dL at any time in the next 2 hours |

## How the simulator works

- Breakfast, lunch, dinner and occasional snacks raise glucose, with a larger rise for higher HbA1c.
- Walking after a meal reduces the rise, and recent steps lower glucose slightly.
- Short sleep raises baseline glucose and the meal response.
- Heart rate follows activity and is lower at night.
- Random noise is added to mimic sensor and body variation.
- The random seed is fixed (`--seed 42`), so everyone gets identical data.

## Limitations

Synthetic data shows that the pipeline works end to end. It does not prove clinical performance.
